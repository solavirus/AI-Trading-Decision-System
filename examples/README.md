# Examples（展示案例）

这里用于存放经过脱敏、可公开复核的真实运行案例。

公开案例必须满足：

- 不包含 API Key（接口密钥）、账户标识、私人 URL（网址）或其他凭证。
- 不暴露不必要的真实账户余额、仓位规模或个人信息。
- 保留足够的 Decision Evidence（决策证据）：输入摘要、AI 判断、结构化决策、Validation（校验）、Risk Guard（风险守卫）与 TESTNET（测试网）执行结果。
- 清楚区分事实、AI 判断和系统执行结果，不把模型输出包装成既定事实。

当前仓库中的历史 `analysis_evidence` 属于开发期证据，不直接作为公开作品案例使用。正式公开前，应先完成脱敏审查，再选择代表样本迁入本目录。
