# Documentation Map（文档导航）

这个目录只保留公开仓库中需要长期维护的文档。第一次查看项目，请先读根目录 `README.md`。

## architecture（架构）

- `architecture/ARCHITECTURE.md` — 当前真实系统架构。
- `architecture/ARCHITECTURE_INDEX.md` — 更细的代码与模块索引。
- `architecture/BINANCE_CAPABILITY_MATRIX.md` — Binance Futures（币安合约）能力边界记录。

## design（产品与决策设计）

- `design/TRADING_DECISION_SYSTEM.md` — Trading Decision System（交易决策系统）的核心产品理念与长期方向。

## engineering（工程契约）

- `engineering/AI_RESPONSE_SPEC.md` — AI Response（AI 响应）契约。
- `engineering/ANALYSIS_PAYLOAD_SPEC.md` — Analysis Payload（分析输入）契约。
- `engineering/PROMPT_BUILDER_SPEC.md` — Prompt Builder（提示词构建）契约。
- `engineering/EXECUTION_SPEC.md` — Execution（执行）契约。
- `engineering/DATA_SOURCE_SPEC.md` — Data Source（数据源）契约。

## development（开发状态）

- `development/PROJECT_STATUS.md` — 当前状态与已知问题。
- `development/ROADMAP.md` — NOW / NEXT / LATER（当前 / 下一步 / 后续）优先级。
- `development/CHANGELOG.md` — 重要里程碑。

## archive（历史归档）

历史项目文档、交接包和早期视觉实验只用于追溯，不代表当前系统状态，也不作为作品主入口。
