# Dashboard Pixel Spec（首页像素规格）

母版尺寸：`1632 × 960`，比例约 `1.70:1`。

以下尺寸是依据母版截图的前端实现基准；响应式时保持比例与层级，不要求小屏逐像素一致。

## 1. 页面骨架

- Sidebar（侧边栏）：264px
- 主内容左边距：26px
- 主内容右边距：34px
- 主内容最大宽度：约 1310px
- 页面背景：暖米色纸张
- 内容纵向间距：16–20px

## 2. Sidebar（侧边栏）

- 固定宽度 264px，满高
- 右侧分隔线：1px，墨色 45% 透明度
- Logo 区高度约 82px
- 导航条宽约 220px，高 48px
- 激活项背景 `#EEF0FF`，蓝色不规则细描边
- 导航项垂直间距约 6px
- 账户卡固定在底部区域之上
- 底部插画与设置区采用 `margin-top:auto`

## 3. Header（页头）

- 高度约 82px
- 左侧标题起点与主网格对齐
- 标题 24px，副标题 12px
- 巫师猫位于页面中上部，宽约 70px
- 新建按钮位于右上，约 170 × 48px

## 4. 顶部区域

采用 7 列逻辑网格：
- 重要事件：3.25fr
- BTC：1fr
- ETH：1fr
- 总市值：1.35fr

整体高度约 218px，列间距 12px。

重要事件卡内部：
- 标题行 38px
- 三条事件行，高 42–46px
- 每条背景为轻暖灰，圆角 10px

行情卡：
- 标题 12px
- 主数字 23px
- 涨跌 13px
- 小图表约占卡片底部 42%
- 币种插画固定在右下或左下

## 5. 数据源概览标题行

- 高 40px
- 左侧标题 17px / 700
- 中部连接状态说明 11px
- 右侧刷新按钮约 136 × 34px

## 6. 主模块网格

桌面端使用 12 列 Grid（网格）：

第一行：
- 市场行情：3列
- 技术指标：3列
- 宏观经济：3列
- 新闻资讯：3列，但高度跨两行视觉区域

第二行：
- ETF：3列
- 链上：3列
- 市场情绪：3列
- 衍生品：3列

第三行：
- 稳定币：3列
- 清算：3列
- 期权：3列
- 添加模块：3列

网格间距：12–14px。

常规卡片高度：约 178px；新闻卡约 286px；衍生品约 190px。

## 7. 卡片内部布局

- Padding（内边距）：16px
- Header（标题区）：32–38px
- 标题图标：30 × 30px
- 实时状态：右上，11px
- 主内容行高：22–25px
- Footer（底部区）：固定贴底，使用 flex + margin-top:auto
- “查看详情”位于右下，13px 蓝色

## 8. 视觉误差验收

以 1632px 宽截图比较：
- 主体布局误差 ≤ 8px
- 卡片尺寸误差 ≤ 6px
- 卡片间距误差 ≤ 4px
- 颜色 ΔE 尽量低于 6
- 装饰位置误差 ≤ 12px
- 不要求 AI 生成文字与插画的笔触完全相同，但要求尺寸、位置、风格一致
