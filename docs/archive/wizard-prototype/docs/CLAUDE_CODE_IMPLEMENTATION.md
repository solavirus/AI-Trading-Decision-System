# Claude Code Implementation Instruction（Claude Code 实现指令）

你是资深前端工程师，不是 UI（用户界面）设计师。

`reference-master.png` 是已经批准的最终视觉母版，不是灵感图。目标是在保留现有后端接口、字段、路由、状态管理和业务逻辑的前提下，尽可能高保真实现该母版。

## 不可更改

- 所有模块名称与模块内容
- API（应用程序接口）请求
- 数据结构与字段映射
- 路由
- 点击行为
- 实时刷新逻辑
- 图表数据与图表类型
- 权限与账号逻辑

## 可以更改

- Layout wrapper（布局包装层）
- CSS（层叠样式表）与 Tailwind（原子化样式框架）类
- 视觉组件外壳
- SVG（可缩放矢量图形）图标与装饰
- 背景纹理
- 轻微交互动画

## 执行顺序

### Phase 1（第一阶段）：审计

1. 阅读现有前端目录。
2. 列出现有页面组件与数据绑定关系。
3. 标记哪些组件只改样式，哪些需要增加包装层。
4. 不写新业务逻辑。

### Phase 2（第二阶段）：设计基础

1. 引入 `src/styles/wizard-tokens.css`。
2. 实现纸张背景和侧边栏。
3. 实现 `DoodleCard` 与 `DoodleIcon`。
4. 暂时不加入大量巫师插画。
5. 截图，与母版比较布局。

### Phase 3（第三阶段）：逐模块迁移

按照顺序迁移：
1. Header（页头）和顶部事件/行情卡
2. 市场行情、技术指标、宏观经济、新闻资讯
3. ETF、链上、市场情绪、衍生品
4. 稳定币、清算、期权、添加模块
5. Sidebar（侧边栏）底部区域

每完成一组就截图比较，不要一次性重写全部页面。

### Phase 4（第四阶段）：插画与精修

1. 只在规范指定位置加入装饰。
2. 使用 `public/assets/wizard/` 中的 SVG（可缩放矢量图形）。
3. 调整纸张纹理、边框抖动、字号与间距。
4. 检查无障碍对比度和点击区域。

## 强制要求

- 不使用 Emoji（表情符号）作为界面图标。
- 不使用 2px 以上纯黑边框。
- 不把真实图表改成手绘静态图。
- 不用整张 PNG（便携式网络图形）作为页面背景伪装实现。
- 不复制母版中的示例数字覆盖真实后端数据。
- 不新增“今日魔法”等母版外内容。
- 不随意移动猫、星星、书本等装饰。
- 不为了“更现代”改变母版布局。

## 验收方式

启动现有项目，设置浏览器 viewport（视口）为 `1632 × 960`，输出截图。将截图和 `reference-master.png` 并排比较，优先修复：

1. 页面骨架与网格
2. 卡片宽高与间距
3. 字号与层级
4. 边框与背景
5. 插画位置
6. 微交互

完成后提供：
- 修改文件清单
- 保持不变的数据接口清单
- 已知视觉差异
- 1632 × 960 截图路径
