# Wizard Notebook Design System（巫师手账设计系统）

## 1. 视觉定位

产品观感：专业量化数据后台 + 巫师研究手账。

比例：
- 85% 专业 SaaS（软件即服务）界面
- 15% 手绘魔法装饰

禁止：儿童画、漫画粗描边、游戏 HUD（平视显示界面）、随意涂鸦、过度泛黄、过多阴影。

## 2. Design Tokens（设计变量）

### 颜色

| 名称 | 值 | 用途 |
|---|---:|---|
| paper-canvas | `#F6F0E3` | 页面底色 |
| paper-card | `#FFFDF7` | 卡片底色 |
| paper-muted | `#F2EBDD` | 次级块、事件条 |
| ink-900 | `#26231F` | 主文字、手绘线 |
| ink-700 | `#514B43` | 次文字 |
| ink-500 | `#81786C` | 描述与时间 |
| magic-blue | `#4E5DE7` | 主按钮、链接、选中态 |
| magic-blue-soft | `#E9EBFF` | 选中背景 |
| magic-gold | `#E3A62F` | 星星、金币、强调 |
| positive | `#198754` | 上涨、在线 |
| negative | `#D84D43` | 下跌、高风险 |
| warning | `#E68B20` | 中影响、警告 |

### 字体

- 中文：`PingFang SC`, `Microsoft YaHei`, sans-serif
- 英文与数字：`Inter`, `ui-sans-serif`, sans-serif
- 手写仅用于 Logo（标志）、极少量装饰标签；正文不使用手写字体。

### 字号

- 页面标题：24px / 700
- 卡片标题：16px / 700
- 主指标：20–24px / 700
- 正文：13px / 500
- 辅助文字：11–12px / 500
- 按钮：13px / 600

### 间距

使用 4px 基线：4 / 8 / 12 / 16 / 20 / 24 / 32。

### 圆角

- 大卡片：16px
- 小卡片：14px
- 按钮：12px
- 标签：8px

### 边框

视觉目标是钢笔轻描边，不是漫画粗黑边。

- 基础：`1.25px solid rgba(38,35,31,.82)`
- 内部事件条：`1px solid rgba(81,75,67,.20)`
- 禁止 2px 以上纯黑边框。

手绘感通过 SVG filter（SVG 滤镜）或伪元素制造，幅度不超过 0.7px。

### 阴影

`0 2px 0 rgba(38,35,31,.10), 0 8px 20px rgba(67,53,34,.035)`

只用于卡片轻微离纸效果。

## 3. 纸张纹理

纹理必须非常轻：
- 噪点透明度 2%–4%
- 纤维线透明度低于 3%
- 不使用明显咖啡渍作为全局背景
- 左侧导航可增加淡横线，模拟笔记页

## 4. 插画规则

所有插画保持统一：
- 黑色钢笔轮廓
- 紫蓝、金黄、浅绿作为局部填色
- 线宽 1.4–1.8px
- 圆头圆角
- 不使用 Emoji（表情符号）

装饰位置固定，不随机：
- Logo：巫师帽
- Header（页头）：巫师猫
- Sidebar（侧边栏）中段：读书黑猫
- Sidebar 底部：药水、水晶球、魔法书
- 市场情绪：水晶球
- ETF：金币袋
- 链上：锁链
- 衍生品：药水瓶/魔杖
- 添加模块：魔法书

## 5. 交互

- 卡片悬停：`translateY(-1px)`，阴影略增
- 按钮悬停：背景加深 4%，右上角星光可轻闪一次
- 动画 140–180ms
- 禁止弹跳、持续闪烁、粒子雨
